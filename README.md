# Open Songbook

Mobile/tablet-first chord sheet viewer (Phase 1 POC).

## Features

- Seeded ChordPro songs (no accounts)
- Key transpose
- Chords + lyrics or lyrics-only
- Optional guitar / piano chord charts
- Horizontal page snap for swipe navigation
- Print stylesheet

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

TanStack Start · React 19 · Vite
